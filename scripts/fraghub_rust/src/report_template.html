Standardization, filtering and sorting of tandem mass spectra from open spectral libraries

1Input files

Spectral library files read in this run, with the source database given to each file and the number of its spectra kept in the outputs (after filtering and removal of duplicates).

2Processing parameters

Filters applied to each spectrum, in the order FragHub applies them, and output formats.

3Spectrum filtering

Each removed spectrum is written, with its reason, in the DELETED_SPECTRUMS folder of the output directory.

4Output libraries

Kept spectra are sorted by separation (LC: liquid chromatography, GC: gas chromatography, DI: direct injection), ion mode and origin (experimental or predicted in silico). Each leaf is one output library. InChIKeys: number of distinct molecules.

5Source databases

Database of origin of the kept spectra. A spectrum found in several databases (duplicates merged) counts for each of them.

6Chemical classes

Chemical classes of the kept spectra, from the internal database: ClassyFire (superclass, class, subclass) and NPClassifier (pathway, superclass, class). Unknown (grey): no class in the database. Click a sector to zoom in, click the centre to zoom out.

Table 3. Classified spectra per level

7Instruments

Instrument manufacturer and model recognized for the kept spectra (FragHub instrument tree). Not found: instrument missing in the file or not recognized.

8Metadata completeness

Share of the kept spectra with a value in each output column (empty, NaN and NOT FOUND count as missing).
